# 🚗 Real-Time EV Dashboard & ADAS Warning System

## 📌 Overview

This repository contains the projects and modules completed during my **Embedded Systems Internship** at **Emertxe Information Technologies**.

The internship focused on developing the building blocks of a **Real-Time Electric Vehicle (EV) Dashboard and Advanced Driver Assistance System (ADAS)** using the **STM32F103C8T6 (Blue Pill)** microcontroller, **Embedded C**, **STM32CubeIDE**, **PICSimLab**, and a **Python-based Dashboard**.

The project demonstrates embedded firmware development, peripheral interfacing, sensor integration, UART communication, and real-time dashboard visualization.

---

## 🎯 Project Objective

The objective of this project is to develop a real-time EV monitoring system capable of:

- Monitoring vehicle parameters
- Reading sensor inputs using STM32 peripherals
- Communicating data through UART
- Visualizing vehicle information on a Python Dashboard
- Understanding the fundamentals of Automotive Embedded Systems and ADAS concepts
